# PortSwitch MCP

MCP server that helps AI coding agents (Claude Code) resolve port conflicts between
local dev environments without destroying data.

## Requirements

- macOS or Linux
- [Docker](https://docs.docker.com/get-docker/) with Docker Compose v2 (`docker compose`)
- **[uv](https://docs.astral.sh/uv/getting-started/installation/)**, the Python package manager

## Setup (once per machine)

In the repo root run:

```bash
uv sync
```

This installs the right Python version and the exact dependency versions from `uv.lock`.

## Try the server by hand

```bash
uv run mcp dev src/portswitch/server.py
```

Opens the MCP Inspector in your browser, where you can call the tools without any AI.

To also see the internal helper functions as tools while debugging, start the debug
entry point instead:

```bash
uv run mcp dev src/portswitch/debug_server.py
```

Agents never see these helpers: `.mcp.json` only registers `server.py`.

## Use it from Claude Code

The server is registered in `.mcp.json`, so it loads automatically.
Start `claude` in the repo root, approve the `portswitch` server when asked,
then run `/mcp` to check it is connected.

## Project layout

```
.mcp.json                 # registers the server for Claude Code (shared via git)
pyproject.toml            # project metadata + dependencies
uv.lock                   # exact versions, generated by `uv sync` (commit it)
.python-version           # Python version uv uses
src/portswitch/server.py  # the MCP server and its tools
src/portswitch/debug_server.py  # same server + helpers as tools, for the Inspector only
```

## Tools and sample responses

### `check_conflicts(path)`

Project `new-project` runs PostgreSQL on port `5432`. Its `docker compose up` fails because
`old-project` already holds that port:

```json
{
  "project": "/Users/josef/tools/new-project",
  "conflicts": [
    {
      "port": 5432,
      "container": "old-project-db-1",
      "compose_project": "old-project",
      "project_folder": "/Users/josef/tools/old-project"
    }
  ]
}
```

For `old-project` itself there is no conflict, because a project does not conflict with itself:

```json
{
  "project": "/Users/josef/tools/old-project",
  "conflicts": []
}
```

### `suggest_free_port(port)`

If port `5432` is taken, the tool suggests the nearest free port:

```json
{
  "requested": 5432,
  "free_port": 5433
}
```

If port `5432` is free, `free_port` equals the requested port:

```json
{
  "requested": 5432,
  "free_port": 5432
}
```
