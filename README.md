# PortSwitch

MCP server that helps AI coding agents (Claude Code) resolve port conflicts between
local dev environments without destroying data.

## Setup (once per machine)

1. Install **[uv](https://docs.astral.sh/uv/getting-started/installation/)** package manager for Python on your machine.
2. In the repo root run:

   ```bash
   uv sync
   ```

   This installs the right Python version and the exact dependency versions from `uv.lock`.

## Try the server by hand

```bash
uv run mcp dev src/portswitch/server.py
```

Opens the MCP Inspector in your browser, where you can call the tools without any AI.

## Use it from Claude Code

The server is registered in `.mcp.json`, so it loads automatically.
Start `claude` in the repo root, approve the `portswitch` server when asked,
then run `/mcp` to check it is connected.

## Project layout

```
.mcp.json                 # registers the server for Claude Code (shared via git)
pyproject.toml            # project metadata + dependencies
uv.lock                   # exact versions, generated by `uv sync` (commit it)
.python-version           # Python version uv uses
src/portswitch/server.py  # the MCP server and its tools
```
